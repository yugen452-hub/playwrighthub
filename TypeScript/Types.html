TypeScript Fundamentals

A quick reference to the type system commonly used in Playwright projects.

Types

Annotate values when an explicit type makes an API or function easier to understand.

const retries: number = 2;
const browserName: string = 'chromium';

Interfaces

Describe the shape of objects passed between helpers, fixtures, and tests.

interface User {
  name: string;
  email: string;
}

Generics

Use generics to preserve useful type information while writing reusable functions and helpers.

function first<T>(items: T[]): T | undefined {
  return items[0];
}
