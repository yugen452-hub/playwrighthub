Asynchronous JavaScript

Understand promises and async functions to coordinate browser actions, network requests, and test setup.

Asynchronous code

JavaScript can start an operation and continue running other code while it waits. Promises represent the result that will become available later.

Promises

A promise can be pending, fulfilled, or rejected. Use then and catch to handle its result, or await it inside an async function.

fetch('/api/profile')
  .then(response => response.json())
  .then(profile => console.log(profile))
  .catch(error => console.error(error));

Async and await

async and await let you write promise-based flows in a readable, sequential style.

async function loadProfile() {
  const response = await fetch('/api/profile');
  return response.json();
}

Error handling

Wrap awaited operations in try and catch when you need to handle rejected promises or report useful context.

try {
  const profile = await loadProfile();
} catch (error) {
  console.error('Could not load profile', error);
}
