API Testing

Notes for checking HTTP behavior and service responses in an automated test suite.

Requests

Send requests directly to an API to check service behavior without driving the browser UI.

const response = await request.get('/api/users');
const users = await response.json();

Status codes

Assert the expected HTTP status before checking the details of a response body.

expect(response.status()).toBe(200);

Authentication

Use the request context's configured headers or storage state to send authenticated API calls.

Response validation

Check important fields and values in the response so tests catch contract regressions, not just successful connections.

expect(users[0]).toMatchObject({
  id: expect.any(Number),
  email: expect.stringContaining('@')
});
