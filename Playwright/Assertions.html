01 Playwright UI Assertions

Meaning / common interview distinction Playwright example
Node is visible; it can still be outside the viewport. await expect(loginBtn).toBeVisible()
No locator match, or matched node isn't visible (e.g. CSS display: none or visibility: hidden). It may still be in the DOM. await expect(loader).toBeHidden()
Node exists in the DOM; it may be hidden or off-screen. await expect(locator).toBeAttached()
Node is absent from the DOM; unlike hidden, it is detached. await expect(locator).toBeDetached()
At least part of the element intersects the viewport. await expect(locator).toBeInViewport()
Control accepts interaction. await expect(button).toBeEnabled()
Control does not accept interaction. await expect(button).toBeDisabled()
Input can be changed by the user. await expect(input).toBeEditable()
Element currently has keyboard focus. await expect(input).toBeFocused()
Checkbox or radio control is selected. await expect(rememberMe).toBeChecked()
Entire rendered text equals expected text (exact match). await expect(msg).toHaveText('Success')
Rendered text includes expected text (partial match). await expect(msg).toContainText('Success')
Attribute has the expected name and value. await expect(input).toHaveAttribute('type', 'email')
Element's class list matches the expected pattern. await expect(menu).toHaveClass(/active/)
Input's current value matches the expected value. await expect(input).toHaveValue('Admin')
Locator matches the expected number of elements. await expect(rows).toHaveCount(10)
Current page URL and title match expectations. await expect(page).toHaveURL('/dashboard') / await expect(page).toHaveTitle('Dashboard')

02 First, compare the context

Playwright UI checks browser locators and auto-waits; Playwright API checks HTTP responses with expect; Postman checks responses with pm.expect. UI assertions have no Postman equivalent.

03 Most-asked interview checks

Question Short answer
toBeVisible() vs toBeInViewport()? Visible can be off-screen; in-viewport means it intersects the viewport.
toBeHidden() vs toBeDetached()? Hidden may still be in the DOM; detached means no DOM node is matched.
toHaveText() vs toContainText()? Exact text match vs partial text match.
toBe() vs toEqual()? Primitive equality vs deep equality for objects and arrays.
What are web-first assertions? Locator assertions that auto-wait for the expected UI state.

04 API Assertion Comparison

Both validate the same HTTP response. Playwright uses Jest-style expect; Postman uses Chai-style pm.expect. Parse with await response.json() in Playwright or pm.response.json() in Postman. Use Ajv for Playwright JSON Schema checks.

05 Negative & soft checks

Playwright Postman
expect.soft(body.id).toBe(101) pm.test('ID', () => pm.expect(body.id).to.equal(101))
Not identical: expect.soft() records a failure and continues the current Playwright test. In Postman, use separate pm.test() blocks to report checks separately.
